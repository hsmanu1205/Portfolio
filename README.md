
# 3D Portfolio 🌟

A modern 3D interactive portfolio website built with cutting-edge web technologies. This project showcases my work in an immersive 3D environment.

## 🚀 Live Demo

Check out the live version deployed on Vercel:  
[![Vercel](https://img.shields.io/badge/Vercel-000000?style=for-the-badge&logo=vercel&logoColor=white)](https://portfolio-orcin-chi-qj1vqllznj.vercel.app/) <!-- Replace with your Vercel link -->

## ✨ Features

- 🎨 Interactive 3D scene with smooth animations
- 📱 Responsive design for all device sizes
- 🖥️ Project showcase with 3D elements
- 🌓 Light/dark mode toggle
- 📬 Functional contact form
- ⚡ Optimized performance with lazy loading

## 🏗️ Installation

```bash
# Clone the repository
git clone https://github.com/hsmanu1205/Portfolio.git

# Navigate to project directory
cd Portfolio

# Install dependencies
npm install

# Start development server
npm run dev
```
